    第8章 CSVTech 技术指导

    本章尽量按照示例 CSV 的真实结构说明 CSVTech 的两种模板。重点不是代码实现，而是你在表格里该怎么填、该怎么选模板。

    8.1 CSVTech 是什么

    CSVTech 是用 CSV 文件描述 Customized Technology File 的方式。你可以先把层信息整理成表格，再用于导入、共享、二次编辑或作为模板继续扩展。 所有支持的 Technology File 都可以转换为 CSV Tech，便于二次编辑和分享。 如果没有合适的 Technology File，可以根据已知叠层手动编辑 CSV Tech，然后再进行 GDS 文件导入。

    8.2 两种模板先看结论

    模板 中文说明 适合你什么时候用
    CSVTech_overlapping_template.csv 显式定义介质层，dielectric 和 metal/via 分开定义 适合需要把介质层细节完整表达出来的场景
    CSVTech_laminate_template.csv 隐式定义介质层，输入数据更少 适合希望快速整理层叠关系的场景

    8.3 CSVTech_overlapping_template.csv

    8.3.2 这张表怎么读

    1. LayerName 是 3D Layout stackup 里要用的层名，应该存在。
    2. Type 的含义是：C=Conductor/Metal layer，V=Via layer，D=Dielectric layer，I=Insulating layer。
    3. Via Group 和 SnapViaGroups 会作用在所有 Via 层上。
    4. Insulating layer 用来定义 TSV insulation thickness，前提是它对应的 LayerName 已在 Via Layers 中定义。
    5. LayerMap 是 GDS 里的层映射，Conductor/Metal 和 Via 层必须有 LayerMap，否则会被忽略。
    6. 一个层可以写多个 LayerMap，中间用空格分隔，例如 86;0 85;0。
    7. TextLayerMap 是用来提取 GDS 里的 net list，前提是 GDS 里有 net 信息。
    8. Thickness 是层厚，默认单位是 um。
    9. Height 是层在 stackup 中的位置。
    10. 低层是最后一个 dielectric layer 的原点，D/C/V 的 Height 都参考这个原点，可以是负值。
    11. LowerLayer 和 UpperLayer 定义 via 层的起止层。
    12. 如果 LowerLayer / UpperLayer 没有填写，程序会按相邻层推断。
    13. LowerLayer / UpperLayer 的优先级高于 via Thickness。
    14. DK、DF、Cond 用于设置层材料属性。
    15. TC1、TC2、Tref 用于温度相关导电率分析。
    16. 只有在 GUI 勾选 UseTemperatureDependMaterial 时，才会使用温度相关材料。

    8.3.3 说明和注意事项

    #Note:
1 以 # 开头的行会被视为注释
2 没有 Type 值的行会被忽略
3 Type 定义：C = Conductor/Metal layer，V = Via layer，D = Dielectric layer，I = Insulating layer
4 Conductor/Metal 和 Via 层必须填写 LayerMap，否则会被忽略
5 Dielectric 层的 Height 是可选项，如果填写，介质层会按 Height 重新排序
6 在 overlapping template 中，Conductor/Metal 层必须填写 Height，并会按 Height 重新排序
7 Via 层的 Height 和 Thickness 由 LowerLayer 和 UpperLayer 定义
8 Insulating layer 用来定义 TSV insulation thickness，它的 LayerName 必须已经在 Via Layers 中定义，否则会被忽略
9 所有 Height 都表示该层的下边界
10 所有长度单位默认是微米

    8.4.2 这张表怎么读

    1. LayerName 同样是 3D Layout stackup 中使用的层名，必须存在。
    2. Type 的含义同上：C、V、D、I。
    3. 这个模板里不建议再放单独的 D 类型 dielectric 层。
    4. The start and end layer is considered as the adjacent layers.
    5. Via Group 和 SnapViaGroups 也会作用在所有 Via 层上。
    6. Insulating layer 仍然用于定义 TSV insulation thickness，LayerName 必须已在 Via Layers 中定义。
    7. LayerMap 对 Conductor/Metal 和 Via 层仍然必须提供，否则会被忽略。
    8. TextLayerMap 依旧用于提取 net list。
    9. Thickness 在 laminate template 中主要用于 Metals/Vias。
    10. Height 表示层在 stackup 中的位置，但通常按层厚累计自动计算。
    11. Manually set the height value is not suggested.
    12. DK、DF 用于 filled material，Cond 用于 metal/via material。
    13. TC1、TC2、Tref 仍然用于温度相关导电率分析。

    8.4.3 说明和注意事项

    1 LayerName 是 3D Layout stackup 中使用的层名，应该存在。
2 Type 定义：C = Conductor/Metal layer，V = Via layer，D = Dielectric layer，I = Insulating layer
    在这个 laminate template 中不应该出现 D 类型的 dielectric layer。
    起始层和结束层被视为相邻层。
    Via Group 和 SnapViaGroups 会作用于所有 Via 层。
    Insulating layer 用于定义 TSV insulation thickness，它的 LayerName 必须已经在 Via Layers 中定义，否则会被忽略。
3 LayerMap 表示 GDS 文件中的层映射。
    Conductor/Metal 和 Via 层必须填写 LayerMap，否则会被忽略。
    一个层可以写多个 LayerMap，中间用空格分隔，例如 86;0 85;0。
4 TextLayerMap 表示在 GDS 中用于提取 net list 的层。
    GDS 中对应的 layermap 应该包含网络信息。
5 Thickness 必须填写，用于 Metals/Vias 层厚度，默认单位是 um。
6 Height 表示该层在 stackup 中的位置。
    所有 Height 都会按 Metal 和 Via 层的厚度累加得到（逆序累加）。
    不建议手动设置 Height。

    8.5 你该怎么选择

    1. CSVTech_laminate 和 CSVTech_overlapping 都是用于 GDS 导入的模板工具，用户可以根据实际情况选用。
    2. CSVTech_laminate 是隐式定义介质层的模板，输入数据更少，更适合希望快速整理层叠关系的场景。
    3. CSVTech_overlapping 是显式定义介质层的模板，需要填写的数据更多，更适合需要把介质层细节完整表达出来的场景。
    4. 如果你需要保留 net 提取相关信息，要填写 TextLayerMap。
    5. 如果你只想先生成 CSV，再后续补充映射，可以先从 CSVTech 开始整理。

    8.6 使用顺序建议

    1. 先复制模板文件。
    2. 再按工艺版本整理 LayerName、LayerMap、Height、Thickness。
    3. overlapping template 先填 dielectric，再填 metal / via。
    4. laminate template 先确认层叠，再填 metal / via。
    5. 保存后作为 Technology File 继续使用。

    8.7 与其他章节的关系

    1. 如果你不确定 LayerMap 怎么填，请先看第7章。
    2. 如果你要调整输出行为，请再参考第6章 Options。
    3. 如果你是用界面导出 CSV，请先参考第3章。
