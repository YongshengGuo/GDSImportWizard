    第6章 Options 详细说明

    本章按“用户如何调参”组织，重点说明对结果影响最大的配置项。

    6.1 如何进入 Options 配置

    1. 在界面中可直接设置 4 个高频参数：
    2. SimplifyDieletricMethod
    3. CreatViaGroups
    4. GenerateComponent
    5. OpenInAedt

    6.2 SimplifyDieletricMethod 选型建议（重点）

    值 界面显示 含义 适用建议 风险/代价
    0 NoSimplify 不做介质合并，尽量保持原始层结构 追求最大结构保真、用于对照验证 层数多，模型复杂，计算代价可能更高
    1 MergeThinLayer 合并较薄介质层（受阈值影响） 工艺里存在大量薄层、希望降低复杂度 薄层细节会被折叠，需要复核关键层
    2 BlockMerge 以分块方式合并（除基底外层）并做平均处理 快速收敛、先跑通流程的工程场景 介质细节简化更明显
    3 MergeByLayer 按层逐级合并（除基底外层）并做平均处理 通常作为默认平衡策略 仍会损失部分介质细节

    配套参数：

    1. ThinDielectricThreshold：控制“薄层”判定阈值，常与值 1 联动。
    2. DkDeviationThreshold：控制介电常数偏差容忍度，影响合并策略灵敏度。

    6.3 界面高频参数（第一优先级）

    参数 默认值 对应界面 作用 常用建议
    SimplifyDieletricMethod 3 下拉框 控制介质层简化策略 一般从 3 开始，不满足精度再切到 0
    CreatViaGroups True 勾选框 对过孔进行分组/聚类 版图过孔较多时建议保持 True
    GenerateComponent True 勾选框 根据 pin 距离自动生成组件 需要器件识别时启用
    OpenInAedt True 勾选框 EDB 生成后自动打开 AEDT 批处理建议 False 以减少 GUI 干扰

    6.4 几何与网格相关参数

    参数 默认值 作用 什么时候改
    FixedSmallLayerGap 0.005 修正过小层间隙，减少网格问题 出现小间隙引发的几何错误时
    SheetLayerThreshold 0.0015 低于阈值的金属层按 2D sheet 处理 超薄金属导致网格困难时
    MetalLayerSnappingTolerance 0.001 导入时图形对齐容差 导入后金属边界错位时
    ReconstructArcsOnLayers None 指定层重建弧/圆 多边形圆化需求明显时
    ArcTolerance 0.2um 弧重建容差 圆弧重建过粗或过细时

    6.5 层筛选与合并相关参数

    参数 默认值 作用 什么时候改
    IgnoreLayersReg air,ctm.,cbm.,dtce.* 用正则忽略层 需要排除特定辅助层时
    UnionPrimitivesOnLayer 1,-1 指定层做图元合并 降低碎片化图元数量时
    ConvertPolygonToCircleOnLayers ubmb,ubump 指定层做多边形转圆 bump/pad 近圆结构较多时
    ConvertPolygonToCircleRatio 0.8 圆化判定比例 圆化过度/不足时微调
    SolveInsideOnLayers None 指定层设置 SolveInside 材料求解策略需要调整时

    6.6 过孔与组件相关参数

    参数 默认值 作用 什么时候改
    CreatViaGroupsOption Method:proximity,Tolerance:5um,CheckContainment:true 过孔分组选项 过孔分组结果异常时
    NotUseViaGroupsOnLayers .tsv.,pmb 在这些层禁用 Via 分组 TSV 或特殊层不适合分组时
    GenerateComponent True 自动组件识别总开关 不需要组件时关闭
    ComponentOnLayers 1,-1 指定参与组件识别的层 只希望部分层做组件识别时
    ComponentPinsDistanceTolerance 100 pin 距离阈值 组件识别过多/过少时

    6.7 导入行为相关参数

    参数 默认值 作用 什么时候改
    GDSIIScalingFactor 1.0 GDS 缩放因子 版图单位不一致时
    ImportDegassingHoles False 是否导入排气孔 工艺明确要求导入时
    ImportDummyNet True 是否导入 Dummy Net 需要严格净网控制时可关
    CutoutPolygon None 仅导入指定多边形区域 大版图裁剪导入时
    DeleteEmptyNonLaminateSignalLayers False 删除空信号层 导入后空层过多时

    6.8 路径与运行控制参数

    参数 默认值 作用 说明
    TechFile None 工艺文件路径 界面与命令行都会设置
    LayerMapFile / layerMap None 层映射文件路径 建议保持与工艺版本一致
    GdsFile None GDS 输入路径 仅 EDB 导入需要
    ControlXmlPath None XML 输出路径 不填时通常自动同名生成
    EdbPath None EDB 输出路径 不填时一般按 GDS 同名生成
    CsvOutPath / CsvOut None CSV 输出路径 不填时通常按 Tech 同名生成
    AedtInstallDir None AEDT 安装目录 可由环境变量自动识别
    AedtVersion None AEDT 版本标识 可在 UI 下拉框选择
    OpenInAedt True 结果生成后是否自动打开 AEDT 批处理建议关闭

    6.9 推荐调参流程

    1. 第一轮先用默认配置跑通。
    2. 第二轮只修改 SimplifyDieletricMethod 验证结果差异。
    3. 第三轮再按问题类型分别调几何参数、层筛选参数、组件参数。
    4. 每次只改 1 到 3 个参数，保留 cfg 版本记录，便于回退。
